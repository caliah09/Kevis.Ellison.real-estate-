# Brand assets

Linda Blue Real Estate, LLC logo, cut out for use as a watermark on Kevis's marketing images.

| File | Use on |
|---|---|
| `linda-blue-logo-transparent.png` | Light or mid-tone photos (near-black logo) |
| `linda-blue-logo-transparent-white.png` | Dark photos (white logo) |

Both are 678 x 322 px with a transparent background.

Standing watermark rule for listing, sold and under-contract images: top-right corner, 92 px wide on a 380 px tile (about 24% of the width), 75% opacity.

These files are for marketing images only. The website does not use them.
