# Monthly social reports

Reports PrimeReach Digital prepares for Kevis, one per month. Open the `.html` file in any browser.

| Month | File |
|---|---|
| October 2026 | `2026-10-social-report.html` (the baseline to compare later months against) |

The folder name starts with an underscore on purpose. GitHub Pages doesn't publish underscore folders, so these reports stay out of kevisellison.com. This repo is public on GitHub, though, so anyone browsing the repo can still open them.
